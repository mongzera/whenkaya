# WhenKaya

**WhenKaya** is a calendar sharing application designed to facilitate scheduling and event management among users.

## Features

* User-friendly interface for creating and managing events
* Shared calendars for collaborative scheduling

## Technologies Used

* **Backend**: PHP
* **Frontend**: JavaScript, HTML, CSS

## Installation

1. Install Laragon https://laragon.org/download/

2. Navigate to ./www/ folder inside Laragon directory and clone Whenkaya from github

1. Clone the repository:

   ```bash
   cd C:/Laragon/www/
   git clone https://github.com/mongzera/whenkaya.git
   ```

2. Navigate to the project directory:

   ```bash
   cd whenkaya
   ```

4. Start all Laragon Services... (PHP, MYSQL)

5. Migrate database by nagivating to http://whenkaya.test/migrate

6. Now, since the database has been migrated, you can use the website as intended

7. Navigate to http://whenkaya.test/

## Usage

After setting up the application:

1. Register or log in to your account.
2. Create a new calendar or join an existing one.
3. Add events to your calendar and invite others.
4. Manage your schedule and receive notifications for upcoming events.
